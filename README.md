# AI-track-extension
The file extension track.mai is a music file extensio that contains several music tracks of the same track but are activated based on listening conditions profiled on the listener.

The goal is to make a song associated with different moments and make it listenable many times without ever being identical to the previous listening.
In a world where LLM models predict playlists and create albums in few seconds, this type of extention file restores music to its most virtuous purpose: expressing human feelings.
